VCP Voice Lab

Creates a consistent set of role voices in Voice Creator Pro for ttv-tts.html (voices.mode: 'perUserLanguage'). Background: readme → Voices.

Before you start
  • This writes new voices into your VCP voice library (existing names are skipped, nothing is deleted). Use Dry run first to listen to the results.
  • The GPU of the VCP PC is busy for a few minutes (roughly 30–60 s per voice incl. checks and priming). Don't run it during a stream.
  • Voice design needs a model that supports it (Qwen3-TTS does). The speech check uses VCP's speech recognition; Japanese, Chinese and Korean are only length-checked by default.

3 · Roles

The role number is part of the voice name, so the same viewer keeps the same role in every language. Keep the same roles for all languages. You can edit the descriptions (English works best).

4 · Options

Keep TTS-{lang} at the start – ttv-tts finds its language pools by that prefix (voices.languagePrefix). Reference audio must be 3–10 s long; longer takes are retried automatically.
