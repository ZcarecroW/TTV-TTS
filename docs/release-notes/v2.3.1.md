**TTV-TTS 2.3.1: TTV-TTS Proxy starts again when it has an OBS link.** 🇩🇪 Deutsch unten.

If your TTV-TTS Proxy closes right after starting (the window flashes and is gone), it has an OBS link stored ("play in OBS through the voice host PC") – that ended every start. **Install this version on the voice host PC by hand**: `TTV-TTS-Proxy_2.3.1_x64-setup.exe` below (a proxy that can't start can't update itself). Everything else stays as it was – your OBS link, viewers and computing queue included.

| | Windows | macOS | Linux |
|---|---|---|---|
| **TTV-TTS** – your streaming PC | `TTV-TTS_2.3.1_x64-setup.exe` | `TTV-TTS_2.3.1_universal.dmg` | `.AppImage`, `.deb` or `.rpm` |
| **TTV-TTS Proxy** – only if Voice Creator Pro runs on another PC | `TTV-TTS-Proxy_2.3.1_x64-setup.exe` | `TTV-TTS-Proxy_2.3.1_universal.dmg` | `.AppImage`, `.deb` or `.rpm` |

**TTV-TTS 2.3.1: TTV-TTS Proxy startet wieder, wenn er einen OBS-Link hat.**

Schließt sich dein TTV-TTS Proxy gleich nach dem Start (das Fenster blitzt kurz auf und ist weg), hat er einen OBS-Link gespeichert („in OBS über den Stimmen-PC abspielen“) – das hat jeden Start beendet. **Installier diese Version auf dem Stimmen-PC von Hand**: `TTV-TTS-Proxy_2.3.1_x64-setup.exe` oben (ein Proxy, der nicht startet, kann sich nicht selbst aktualisieren). Alles andere bleibt, wie es war – auch dein OBS-Link, die Zuschauer und die Rechenschlange.
