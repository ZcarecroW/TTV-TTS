**TTV-TTS is now a desktop app** for Windows, macOS and Linux – your Twitch chat, read aloud in real voices by Voice Creator Pro on your own graphics card. 🇩🇪 Deutsch unten.

📖 **[Documentation](https://zcarecrow.github.io/TTV-TTS/)** · 🔊 **[Hear the voices](https://zcarecrow.github.io/TTV-TTS/#voices)**

### Which file?

| | Windows | macOS | Linux |
|---|---|---|---|
| **TTV-TTS** – your streaming PC | `TTV-TTS_2.0.0_x64-setup.exe` | `TTV-TTS_2.0.0_universal.dmg` | `.AppImage`, `.deb` or `.rpm` |
| **TTV-TTS Proxy** – only if Voice Creator Pro runs on another PC | `TTV-TTS-Proxy_2.0.0_x64-setup.exe` | `TTV-TTS-Proxy_2.0.0_universal.dmg` | `.AppImage`, `.deb` or `.rpm` |

The apps aren't signed with a paid certificate: Windows shows SmartScreen (**More info → Run anyway**), macOS asks once (**System Settings → Privacy & Security → Open Anyway**). See [Installation](https://zcarecrow.github.io/TTV-TTS/installation/).

### What's new

- Every viewer gets their own voice and keeps it, in every language.
- 20 presets with 240 voices each – computed once, downloadable ready-made, or write your own with any AI.
- The TTV-TTS Proxy for a second PC: pairing, encryption, firewall check, watches and restarts Voice Creator Pro.
- Emotions from chat, translate for me, voice effects and VST3/CLAP plugins.
- Approval queue, replay, global hotkeys, Stream Deck / Streamer.bot API, system voice fallback.
- Announcements of subs, raids and cheers (follows and rewards with the optional Twitch login).
- Friends over the internet, voice packs, a speed monitor that restarts Voice Creator Pro when it gets slow.

Coming from 1.x? Your voices are adopted as *Classic 30*; the old OBS browser source keeps working. See [Coming from 1.x](https://zcarecrow.github.io/TTV-TTS/from-v1/). Full list: [CHANGELOG](https://github.com/ZcarecroW/TTV-TTS/blob/main/CHANGELOG.md).

**TTV-TTS ist jetzt eine Desktop-App** für Windows, macOS und Linux – dein Twitch-Chat, vorgelesen in echten Stimmen von Voice Creator Pro auf deiner eigenen Grafikkarte.

📖 **[Dokumentation](https://zcarecrow.github.io/TTV-TTS/de/)** · 🔊 **[Stimmen anhören](https://zcarecrow.github.io/TTV-TTS/de/#voices)**

**Welche Datei?** *TTV-TTS* für deinen Streaming-PC; *TTV-TTS Proxy* nur, wenn Voice Creator Pro auf einem anderen PC läuft – dort installieren. Windows zeigt beim ersten Start SmartScreen (**Weitere Informationen → Trotzdem ausführen**), macOS fragt einmal (**Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen**). Siehe [Installation](https://zcarecrow.github.io/TTV-TTS/de/installation/).

**Neu**: eigene Stimme für jeden Zuschauer · 20 Presets mit je 240 Stimmen · der Proxy für einen zweiten PC · Gefühle aus dem Chat, Übersetzung, Stimmeffekte, VST3-/CLAP-Plugins · Freigabe, Wiederholen, Tastenkürzel, Stream-Deck-API, Systemstimme als Ersatz · Ansagen · Freunde über das Internet · Stimmenpakete · Tempo-Wächter.

Du kommst von 1.x? Deine Stimmen werden als *Classic 30* übernommen; die alte OBS-Browserquelle funktioniert weiter. Siehe [Von 1.x umsteigen](https://zcarecrow.github.io/TTV-TTS/de/from-v1/).
