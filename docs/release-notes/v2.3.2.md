**TTV-TTS 2.3.2: computing voices no longer stands still.** 🇩🇪 Deutsch unten.

If TTV-TTS Proxy shows a computing job that doesn't move while Voice Creator Pro does nothing: a chat sentence, preview or friend's request that gave up while it waited for VCP kept computing waiting for good. Fixed. **Both apps update themselves**; the update restarts the proxy, and computing goes on where it stopped.

| | Windows | macOS | Linux |
|---|---|---|---|
| **TTV-TTS** – your streaming PC | `TTV-TTS_2.3.2_x64-setup.exe` | `TTV-TTS_2.3.2_universal.dmg` | `.AppImage`, `.deb` or `.rpm` |
| **TTV-TTS Proxy** – only if Voice Creator Pro runs on another PC | `TTV-TTS-Proxy_2.3.2_x64-setup.exe` | `TTV-TTS-Proxy_2.3.2_universal.dmg` | `.AppImage`, `.deb` or `.rpm` |

**TTV-TTS 2.3.2: Das Berechnen der Stimmen bleibt nicht mehr stehen.**

Zeigt TTV-TTS Proxy einen Rechenauftrag, der sich nicht bewegt, während Voice Creator Pro nichts tut: Ein Chat-Satz, eine Hörprobe oder die Anfrage eines Freundes, die beim Warten auf VCP aufgegeben hat, ließ das Berechnen für immer warten. Behoben. **Beide Apps aktualisieren sich selbst**; das Update startet den Proxy neu, und das Berechnen geht dort weiter, wo es stehen geblieben ist.
